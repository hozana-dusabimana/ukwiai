# AI_FORCE_HEURISTIC=1 + AI_DISABLE_OBJDET=1).

# Excludes tensorflow / torch / transformers / accelerate / kaggle on purpose:
#  * tensorflow-cpu has NO aarch64 wheel (the box is ARM64), so the full

#    is loaded lazily only when a trained CNN is used, and torch/OWLv2 only when
#    object detection is enabled. Both are disabled in prod.
# To run the full CNN + OWLv2 stack (on a larger, ideally x86 box), build with
# the default requirements.txt instead and flip the two AI_* flags off.
